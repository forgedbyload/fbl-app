## Claude Code Implementation Prompt

```
Implement the 6-day training plan from the training-plan.md file.
Read the full file before starting.

Create all sessions in Supabase for both Week A and Week B.
Use the existing exercises table to look up exercise UUIDs by name.

For each session insert into sessions table:
- week: 'A' or 'B'
- weekday: 'mo','di','mi','do','fr','sa'
- dup_mode: 'kraft','hyper','vol'
- rest_seconds: 180 for kraft, 90 for hyper, 60 for vol
- work_seconds: null (all sessions are rep-based, not timed)
- exercise_ids as JSONB: [{exercise_id: UUID, sets: N}]
  For supersets: list Exercise A then Exercise B alternating
  Pause between superset pairs only (0s pause between A and B within pair)
- title: auto-generate from dup_mode + body regions

Session exercise order for supersets:
[SS1-A, SS1-B, SS2-A, SS2-B, SS3-A, SS3-B]
This ensures A and B alternate in the timer.

Kraft sessions: straight order, no superset pairing.

After inserting all 12 sessions (6 days × 2 weeks):
- Update week_assignment in exercises table:
  Each exercise used in Week A → add 'A' to week_assignment array
  Each exercise used in Week B → add 'B' to week_assignment array
  Exercises in both → ['A','B']

Commit after completion:
git add . && git commit -m "feat: 6-day training plan Week A+B imported" && git push
```

## Evidence Base

- Supersets (Agonist-Antagonist): Schoenfeld et al. – same hypertrophy gains, 36% less time
- Straight sets for Kraft: necessary for maximal motor unit recruitment at 4-6 RM
- Biceps priority: 20 sets/week (Di Vol + Do Hyper + Sa Vol) – at upper limit of effective range
- Abs priority: 18 sets/week distributed across 4 sessions – prevents accommodation
- 30-min sessions achievable via supersets + minimal transition time
